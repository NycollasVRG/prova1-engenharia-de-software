# Engenharia de Software Moderna — Guia Visual (Capítulos 1 a 4)

Aplicação web estática, interativa e altamente visual contendo os **enunciados completos e as respostas detalhadas** para todas as 53 questões dos **Capítulos 1 a 4** da obra *Engenharia de Software Moderna*, de autoria do Prof. **Marco Tulio Valente**.

---

## 🚀 Funcionalidades

- **📚 Conteúdo Completo (Caps. 1 a 4):**
  - **Capítulo 1:** Introdução (11 questões) — Dificuldades acidentais/essenciais, RF vs. RNF, Verificação vs. Validação, limites de testes, cálculo de teste exaustivo de 64 bits, custos de manutenção (80%+), refactoring, classificação de sistemas (A, B e C) e ética profissional (caso Volkswagen).
  - **Capítulo 2:** Processos de Software (19 questões) — XP vs. Scrum, papéis ágeis, Product Backlog, Story Points, Sprint Review vs. Retrospectiva, histórias de usuário com grafo de dependências, Scrum vs. Kanban com quadros mockados, Lei de Little e frequência de releases.
  - **Capítulo 3:** Requisitos de Software (15 questões) — Questão POSCOMP 2010, técnicas de elicitação, os 3C's, histórias de usuário para rede social, anti-patterns, histórias épicas, gold plating, casos de uso estruturados com fluxos de exceção, MVPs e testes A/B no comércio eletrônico com wireframe do *MusicStream MVP*.
  - **Capítulo 4:** Modelos (8 questões) — Os três usos de UML (Fowler), Engenharia Reversa e Avante, diagramas de classes em SVG, composição ENADE 2014, diagrama de sequência detalhado para chamadas recursivas/autochamadas e diagrama de atividades comparando nós de *Merge* e *Join*.

- **📐 Diagramas Vetoriais em SVG Puro:**
  - Diagramas de Classes UML com navegabilidade, herança, dependência e composição.
  - Diagrama de Sequência UML completo (`a.m5()`) com linhas de vida, ativações e retornos.
  - Diagramas de Atividades com correções de deadlock entre nós de Decisão e Merge.
  - Mockups visuais de Quadros Scrum e Kanban com limites WIP.

- **🧠 Modo Estudo Interativo:**
  - Permite ocultar as respostas para testar seus conhecimentos antes de conferir o gabarito.
  - Os enunciados permanecem visíveis para leitura e cada resposta pode ser revelada individualmente com um clique.

- **🔍 Busca Instantânea e Filtros:**
  - Filtro rápido por capítulo (Todos, Cap. 1, Cap. 2, Cap. 3, Cap. 4).
  - Busca textual em tempo real que pesquisa tanto pelos enunciados quanto pelas respostas.

- **🌓 Tema Claro e Escuro:**
  - Alternância de tema com persistência em `localStorage`.
  - SVG e tipografia com contraste balanceado para estudo prolongado.

- **🖨️ Otimizado para Impressão e PDF:**
  - Estilos específicos para exportação limpa via `@media print`.

## 🛠️ Tecnologias Utilizadas

- **HTML5** semântico.
- **CSS3** puro com CSS Variables, Grid, Flexbox e design responsivo (desktop, tablet e celular).
- **JavaScript (ES6+)** vanilla (sem frameworks ou dependências externas).
- **SVG vetorial** nativo.

## 💻 Como Visualizar Localmente

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
# Clonar o repositório
git clone https://github.com/NycollasVRG/engenharia-de-software-moderna.git

# Acessar a pasta
cd engenharia-de-software-moderna

# Abrir index.html no navegador (ou simplesmente dar duplo clique no arquivo)
```
